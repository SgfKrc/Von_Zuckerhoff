## 2. 瓦片

### 2.1 图集组织

`art/tiles.ts` 里每个瓦片是一个**字符网格字符串**，由 `build.ts` 转成 ImageData。

```ts
// 一个瓦片 = 16 行 × 16 字符，字符映射到调色板索引
export const T_FLOOR_STONE = `
0000000000000000
0111111111111110
...`
```

- 字符 `0-9a-f` → 调色板索引；`.` 或空格 → 透明
- 三阶明暗：每块建材至少给出 暗/中/亮 三档
- 统一光源：**左上**

## 5. 图纸层渲染

- 覆盖在现实层之上，纸底 `#e8e0d0` at 88%，然后画墨线
- 线条 1px，抗锯齿关闭（`imageSmoothingEnabled = false`）
- 结构符号按 `SYSTEM_DESIGN.md §1.2` 的表
- 缺笔（`inkblot`）用**抖动**：每帧随机偏移 1px，配 `#b04040`
- 缺页（`torn`）用留白 + 右上角折角
- 玩家补的线用**标注蓝**，闪一下再固定
- 错线用**标注红**，且带轻微抖动

**性能**：图纸层只重绘变化格，不做全屏重绘。

## 6. 远景贴图（允许外部素材）

这是本作唯一使用外部图片的地方。规格 **768×432**（2 倍内部分辨率），双层视差。

| 用途 | 内容 | 优先级 |
| --- | --- | --- |
| 标题画面 | 雾中的聚斯霍芬堡剪影 + 红月 | P0 |
| 窗外景（卧室/餐厅/时计塔） | 黑森林、山脊、月相 | P0 |
| 山路远景 | 雾中的森林与古堡轮廓 | P0 |
| 梦境（以太海） | 灰白虚空 + 巨大几何轮廓 | P1 |
| 白色花海 | 无尽白花与蓝紫星空 | P1 |

**风格约束**：低饱和、冷调、雾化、颗粒感。禁止高饱和插画风。像素画与写实插画之间用"雾"和"颗粒"过渡。

## 7. UI

- 对话框：半透明黑底（`#0b0d10` 82%），上边框一条 `#7a6a3a` 细线
- 字体：正文用 16px 点阵中文字体（如"方舟像素""Zpix"），标题可用衬线
- HUD 角落：糖罐（糖数）、墨水瓶（墨水）、一根细的"确信"条（不用血条造型，用**图纸卷边**的造型）
- 甜度不显示数值，只让 UI 边缘泛白、文字变圆润
- 位阶不显示，只让立绘与眼睛变化

全部 WebAudio 合成，无外部音频文件。沿用参考项目的合成器思路，但**曲风不同**。

### 8.1 音色

| 管风琴 | 方波叠加 + 轻微失谐 + 低通 | 古堡、宗教、结局 |

## 10. 生产管线

1. **瓦片/精灵**：写字符网格（16×16 或 16×24），跑 `npm run check:art` 预览成 PNG 图集
2. **地图**：字符网格（每行等宽，至少 26×14），跑 `npm run check:map` 校验等宽、传送点、struct 层完整性
3. **远景**：外部图片放 `public/bg/`，命名 `bg_<场景>.png`，768×432；缺失时自动回退到程序化剪影
4. **立绘**：同字符网格，48×64，三阶明暗
5. **音频**：全部在 `audio.ts` 里用参数定义，无文件

**验收工具**（必须在 M1 就做出来）：

- `check:map` — 行等宽、传送目标存在、传送点不在实体/实体瓦片上、struct 层尺寸一致
- `check:art` — 所有字符网格尺寸正确、颜色索引在调色板内
- `check:script` — 所有对话 `next`/`teleport`/`battle` 目标存在，无死循环引用
- `check:reach` — 从章节起点出发，所有必需交互点可达（BFS）

## 11. 角色设计规范（避免"样板化路人味"）

> 本节是用户在第一次试玩后的明确反馈，属于**硬约束**，后续所有角色（玛尔塔、赫尔曼、维多利亚、埃里希、维内塔、罗泽莉亚……）都必须遵守。

### 11.1 剪影特征：三秒辨认

每个角色必须有一个**在纯黑剪影下也能辨认**的特征。没有这个特征的角色不准进游戏。

| 角色 | 剪影特征 | 参考形象 |
| --- | --- | --- |
| 弗里德里希 | 蓬松红发 + 窄肩长身 | 《银河英雄传说》齐格菲·吉尔菲艾斯 |
| 艾玛 | 盘发轮廓 + 方正白色围裙前襟 | 《东方Project》十六夜咲夜 |
| 赫尔曼 | 比他人高 2px + 极窄的燕尾服下摆 | 维多利亚时代的资深管家 |
| 玛尔塔 | 头巾 + 宽围裙 + 圆身体 | 乡村厨娘 |
| 维多利亚 | 红发垂落 + 黑长裙 + 立领 | 浪漫主义肖像画 |

### 11.2 头部结构：不许是"方块 + 两点"

16×24 的行走图头部只有约 8×8 像素，但仍必须交代：颅顶 → 额 → 眉骨 → 眼窝 → 鼻 → 颧 → 下颌 → 颈。允许简化顺序，不允许省略**眉骨与下颌**——这两处决定了"有没有脸"。

立绘（48×64）必须交代全部结构，且左右不完全对称（眉高、嘴角、发绺方向各差 1px），对称会立刻显出"人偶感"。

### 11.3 肤色：禁止石膏白

**禁止**用 `#d8dde5`（骨白）或任何冷灰色做人类皮肤。骨白只用于亚麻、纸张、月光。

| 角色 | 基色 | 暗部 | 高光 | 说明 |
| --- | --- | --- | --- | --- |
| 弗里德里希 | `#dcb49a` | `#b08a72` | `#f0d0b8` | 苍白但有血色 |
| 艾玛 | `#e4c8b8` | `#b89888` | `#f4e0d0` | 比常人更白，但**白得均匀、没有血色变化**——她是被造物，这是唯一允许的"不自然" |
| 玛尔塔 | `#e0b898` | `#b08868` | `#f2d4b4` | 常年待在厨房，偏红 |
| 赫尔曼 | `#c8b0a0` | `#9a8478` | `#dcc8b8` | 灰败，但仍是肉色 |

**检查方法**：把立绘缩到 50% 看，如果脸看起来像纸或石膏，就是错的。

### 11.4 立绘与行走图的一致性

同一个角色的立绘与行走图必须能对上：发色、发型轮廓、眼睛颜色、服装主色。切换时不能有"这是两个人"的感觉。

### 11.5 艾玛的特殊约束

她全篇只有一个半表情。立绘 `emmaQuiet` 与 `emma` 的差别**只允许在眼皮**（压低 1px）。不要给她惊喜、愤怒、悲伤——她的脸是"被造出来的"，这一点要在美术上就成立。嘴角那半个上扬，全篇只出现 3 次。

## 12. 电影分镜（演出规范）

> 用户要求序章开场有"电影分镜感"。这套规范同样适用于后续所有关键场景。

### 12.1 序章开场

总长 **18.5 秒**，两个镜头 + 一次遮挡转场。可按任意键跳过（跳到 16.4s 的定格帧）。

| 时间 | 镜头 | 画面 |
| --- | --- | --- |
| 0.0–1.0s | — | 全黑 |
| 1.0–3.4s | **A · 远** | 渐显黑森林群山（三层视差：远山 / 冷杉林 / 雾） |
| 3.4–6.4s | **A · 下移** | 镜头上滚，露出**纵向铁轨**（双轨从画面下缘收束于消失点 (192,96)） |
| 6.4–10.4s | **A · 迎面** | 车头沿纵向轨道驶来，宽度 18px → 380px |
| 10.4–11.4s | **转场** | 继续放大到 1500px，锅炉前脸 + 车灯白光**占满画面** |
| 11.4–11.9s | **黑** | 纯黑 0.5 秒（硬切，无旋转、无叠化） |
| 11.9–14.4s | **B · 侧视** | 横向铁轨 + 列车左→右横穿，车窗逐扇亮 |
| 14.4–16.4s | **B · 定格** | 最右那扇窗（窗内两个头肩剪影），其余压暗 |
| 16.4–18.5s | — | 淡出到黑 → `finishOpening()` |

**为什么必须这样切**：车头迎面（纵向）与列车横穿（横向）是两个镜头。如果让横向铁轨上跑一辆迎面而来的车，方向就是矛盾的；如果直接硬接，又没有过渡。解法是**遮挡转场**——让车头真的填满屏幕，再黑一帧，观众自己补上"镜头被撞了一下，然后从侧面看见它"。

**三条实现要点**：
1. 纵向铁轨是**预渲染 + 随相机 1:1 平移**的，所以是"镜头下移露出铁轨"，不是贴图滚动。
2. 车头宽度是指数增长（6.5s=19px / 8.5s=89px / 10.8s=783px），中心点先下降到 150 再转为"以车灯为锚"，确保贴脸时灯仍在画面中央。
3. 镜头 A 只画纵向轨、镜头 B 只画横向轨——**全片不存在"横向轨道 + 正面车头"同框的帧**。

### 12.2 分镜的三条纪律

1. **先景后人**。任何新场景，第一个镜头不许给角色，先给环境。
2. **镜头必须有位移**。静止的画面不叫分镜，叫壁纸。允许的位移：横移、竖移、推近、拉远。
3. **黑屏是标点**。切场景前后各留 0.8–1.2 秒黑屏，不要硬切。

### 6.1 远景接入的工程做法（已实装）

| 项 | 做法 |
| --- | --- |
| 素材 | `public/bg/gothic.jpg`（由 1920×1080 PNG 重采样到 1280×720、JPEG 质量 82，3.7 MB → 159 KB） |
| 路径常量 | `constants.ts` 的 `GOTHIC_BG_SRC`，标题与游戏内共用一份 |
| 预加载 | 模块级 `new Image()`，`onload` 后烘焙到离屏画布并置 ready；未就绪直接跳过，不阻塞 |
| 风格统一 | 烘焙时用 `saturation` 混合模式去饱和 + 冷蓝叠加 + 固定 seed 的 2×2 抖动点，**只烘焙一次**，绝不逐帧变化 |
| 视差 | 横向锁死、纵向 `camY * 0.25` |
| 压暗 | 每帧叠 `rgba(8,10,16,0.45)`，让它沉到瓦片之下 |
| 单文件内联 | `package-single-html.mjs` 的 `inlinePublicImageReferences()` 把 `./bg/*.(png\|jpg\|webp\|gif)` 转成 base64 |

**关键教训**：俯视相机的镜头永远跟着玩家，镜头里只会有玩家周围的 13 行。远景要可见，要么地图够高，要么给这张地图单独偏移镜头——本作用了后者：`GameMap.camBiasY`（负值 = 镜头上抬）。`gate` 设为 `-72`，玩家因此落在画面偏下，上方留出天空与城堡远景。

**体积纪律**：3.8 MB 的 PNG 直接 base64 会把单文件推到 5.2 MB。先重采样到 1280×720 再转 JPEG（质量 82），159 KB，单文件回落到 559 KB。远景本来就是模糊的，分辨率减半看不出差别。
### 11.6 脸部规格（踩过两次坑，务必照此执行）

> 用户反馈史：
> - 第一次：「样板化路人味，肤色过白」→ 重画
> - 第二次：「大眼娃娃」→ 收眼、加长鼻、收下颌
> - 第三次（48×64 版）：「上一版立绘的脸部会更好」
> - 第四次（48×48 版）：「脸很瘦长」「艾玛画得偏老」

#### 正确的脸型（48×64 与 48×48 都适用）

| 部位 | 数值 | 说明 |
| --- | --- | --- |
| 脸最宽 | **14–16px** | 不要再窄。窄了就是"瘦长" |
| 下颌 | **12px** | 不要收到 8–10，那会变成尖下巴 |
| 下巴 | 10px | 末端略平，不要收成尖 |
| 眼宽 | **3px**（立绘）/ 2px（行走图） | 上眼睑一道横线，虹膜只占中间 1px，左右各留 1px 眼白 |
| 鼻 | **2 行**：鼻梁 + 鼻头 | 1 行显得平，3 行显得长 |
| 眉与眼之间 | 留 **1 行空隙** | 贴着就凶 |

#### 绝对禁止（这是"显老"的根源）

1. **眼下的暗部**——只要在虹膜正下方画一条 `skinShade` 的横线，所有人立刻老十岁
2. **法令纹**——嘴角到鼻翼之间不许有暗线
3. **眼下阴影块**——眼窝可以做，但只能做在眉骨下方，不能做在眼球下方
4. **过长的中庭**——鼻梁到嘴的距离超过 5 行就会显老

#### 艾玛的特殊要求

- 她的脸要比弗里德里希**更圆一点**：脸宽 16，下颌 13，下巴 11（各比男角宽 1px）
- 脸颊两侧各留 1px 的 `skin` 高光，让脸显得饱满（不是婴儿肥，是"没长开"）
- 她只能有一种表情，但"平静"不等于"面无表情"——嘴角保持 0.5px 的平直，不要下压

把立绘放大 4 倍，问三个问题：
1. 脸看起来是"瓜子脸"还是"瘦长脸"？（要前者）
2. 眼下有没有暗线？（不能有）
3. 艾玛看起来是二十多岁还是四十岁？（要前者）
