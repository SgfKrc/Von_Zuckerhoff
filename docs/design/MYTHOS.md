# 里线神话：宝石、三柱神与那场梦

> **本文是里线的唯一真相源。** 表世界的一切设定必须与本文自洽，但**不得**在表世界文本里提前泄露。
> 标注约定：【原】＝原作已写；【推】＝原作留下、由此推得；【改】＝本作新增。
> 副标题：**宝石**（Von Zuckerhoff: The Gem）

---

## 0. 一句话

> **这个家族守着的不是一座城堡，是一场梦。**
> **梦醒的时候，梦里的人不会死——他们只是从来不曾存在。**

---

## 1. 三颗宝石 = 三道门

原作把三颗宝石写成"会做梦的石头"，是"祂梦中的碎片""祂意识的分形"（L3124–L3126）。本作把它们落成确切的对应。

| 宝石 | 原作称呼 | 颜色与终点 | 本作对应 | 在家族里的化身 |
| --- | --- | --- | --- | --- |
| 罗马尼亚红宝石 | 生命 | 「红的终点是黑」（L6092） | **原始月亮 · 莎布·尼古拉斯** | 维多利亚的血脉。生育、血肉、无定形。吸血鬼教廷 |
| 挪威祖母绿 | 混沌 | 「绿的终点是混沌」（L7286） | **千面之月 · 奈亚拉托提普** | 面孔碎片。剥脸仪式、十二个名字、恶魔 |
| 突尼斯大钻石 | 终极 | 「终极没有起点没有终点，终极就是终极」（L7286） | **门之钥 · 犹格·索托斯** | 时计塔。门、时间、全知、月兽 |
| ——（树本身） | 生命树 | 「树梢位于底部，树根位于无限高处」（L6149–L5155） | **阿撒托斯** | 梦本身。箱庭、聚斯霍芬堡、所有"角色" |

**关键推论**：三颗宝石是**三个出口**，生命树是**那栋房子**。房子不属于任何一颗宝石——房子是做梦的那个东西的颅骨。

## 2. 四层存在

```
                    【阿撒托斯】——万物之主，盲目痴愚，在混沌中心吹笛
                          │  （梦）
        ┌─────────────────┼─────────────────┐
        │                 │                 │
   【莎布·尼古拉斯】  【奈亚拉托提普】   【犹格·索托斯】
     原始月亮·红         千面之月·绿        门之钥·无色
        │                 │                 │
   血肉／生育／无定形  面孔／化身／疯狂   门／时间／全知
        │                 │                 │
   吸血鬼（维多利亚）   恶魔（面孔碎片）    月兽（时计塔）
        │                 │                 │
        └────────┬────────┴────────┬────────┘
                 │                 │
            【人类】            【箱庭】
        （序列九以下的枝条）  （被梦出来的角落）
```

【原】原作给过的三条原始序列——「原始月亮（生命）／千面之月（恶魔）／门之钥（门）」，以及"高层互不交叉、低层交错重叠衍生独立分支"（L8197–L8199）。本作不新造体系，只把三个名字补上。

【推】原作反复出现但从未点名的那个空括号【】，就是**阿撒托斯**。原文四处留空（L945、L987、L3134、L5165–L5167、L6985）。本作**永不填这个名字**——里线也不填。玩家只能从三柱神的方位反推出"上面还有一个"，这就是留白的价值。

## 3. 生命树是倒的

【原】主角在梦里看见的树："树梢位于底部，树根位于无限高处"（L5149–L5155）。这不是卡巴拉的正常生命树，是**逆位**的。

【推】逆位意味着：**这棵树是从下面长上来的**。它的根不在土里，在"无限高处"——也就是在梦外面。它不是世界的结构，它是**从梦外面伸进梦里的一只手**。

【改】本作的用法：

| 正统生命树 | 本作的树 |
| --- | --- |
| 树根在土里，树梢向上 | 树梢在底部（人所在处），树根在无限高处 |
| 越往上越接近神 | 越往下（树根方）越接近阿撒托斯 |
| 人是果实 | 人是**叶子上的虫** |

原作那句"人类在某一根枝上像蚂蚁在叶上"（L5157）在这里得到解释：不是比喻，是尺寸关系。

## 4. 祖克霍夫家族真正在做什么

### 4.1 表面生意：糖

【原】家族以糖起家，创始人克劳斯·施密特，“比任何人都洁白、都比任何人都甜美"的白糖（L366）。旧贵族叫他们"糖贩子"（L370）。

【原】女工因长期吸入糖粉，"肺里长满了白色的结节，死的时候咳出来的痰都是甜的"（L388）。

【改】糖的隐喻在里线里落到实处：

> **精炼。把浑浊的东西煮白、结晶、取名。**
> 这就是这个家族全部的本事——他们不是种甘蔗的，是**把别处来的东西变成能叫得出名字的白色方块**。

家族做的从来不是糖。是**把梦外面的东西，提炼成梦里面能存在的东西**。

### 4.2 真实功能：续画

【改】聚斯霍芬堡是箱庭——阿撒托斯梦中的一个角落。梦会醒，**醒的方式是"没人再看着它"**。

每一代家主做的事，本质上只有一件：**续画**。

| 家主 | 续画的方式 | 原作依据 |
| --- | --- | --- |
| 克劳斯（初代） | 建了糖庄，给了这个梦一个"名字" | 【原】L362–L378 |
| 汉斯（二代） | "守护家族。守护糖庄。" | 【原】L6042–L6048 |
| 埃里希（三代） | 去特兰西瓦尼亚，做剥脸仪式，带回完整月兽骨架——他把**门**钉住了 | 【原】L6052–L6056、L6413 |
| 鲁道夫（四代） | 航海。"大海是黑色的。"他把**边界**画了一遍 | 【原】L6060–L6064 |
| 威廉 | 写了《黑格林童话》——**他把这个梦写成了书**。书是让梦可被"读"的方式 | 【原】L933、L4576 |
| 克内泽贝克 | 写了《祖克霍夫的召唤术全典》——**他把接口写成了手册** | 【原】L4877–L4889 |
| 弗里德里希·威廉（曾祖父） | 造了艾玛。**他造了一个不会离开的读者** | 【原】L6323、L7308 |
| 阿尔弗雷德（外祖父） | 设计改良仪式，让女儿离开。**他第一次试着让人走出画** | 【原】L5835–L5861 |
| 赫尔曼 | 守门人。奉阿尔弗雷德遗愿"终结痛苦"——**他要让梦醒** | 【原】L7242–L7250 |

**所以这个家族不是血脉，是一份工作。** 每一代都被叫回来做同一件事，而他们各自都想用不同的方式做完它。

### 4.3 为什么一代代都痛苦

【原】阿尔弗雷德手稿：「只要活着，痛苦就会累积。」（L7310）
【原】赫尔曼：「只要祖克霍夫还存在，痛苦的根源、悲剧的根源就永远不会终结。」（L7250）

【改】因为**做一个梦的边框是很痛的事**。你不是梦里的人，你是那条框。你不能出去，也不能进来。你能做的只有看着。

这就是赫尔曼为什么没有脸。**边框没有脸。**

## 5. 四个人，四种位置

| 人 | 是什么 | 里线真相 |
| --- | --- | --- |
| **弗里德里希** | 【改】**唯一一个"纯净的"人**——没有面孔碎片，因为母亲被改良仪式洗干净了 | 正因为他纯粹，他是**梦外面的人被塞进梦里**。所以他既是唯一的幸存者，也是唯一不能被梦容纳的人。梦醒后他会死——**因为他从来没有被画进去过** |
| **艾玛** | 【原】造物。用维多利亚的血和"那些骨头"造的（L6323） | 【改】她是**"读者"**。曾祖父造她，是为了让这个梦有一个永远不会离开的观众。梦在，她在；梦醒，她也"不存在"——但她不痛，因为她从来不是被梦出来的，是被**造**出来的 |
| **赫尔曼** | 【原】无脸，机油味，守门人 | 【改】他是**上一任画师的笔**。阿尔弗雷德死后，笔还在动。他不是坏人，他是**一个还在执行上一条指令的工具** |
| **玛尔塔** | 【原】厨娘，热情，话多 | 【改】她是最"像人"的那个。她被"擦掉"是因为她看见了边框。**她的死是这场梦里唯一一次真正的谋杀**——其余的一切都只是被画出来又被擦掉 |

## 6. 一周目为什么注定失败

【改】这是本作最重要的结构决定。

**一周目的玩家在表世界里做的一切努力，都不会改变结局。** 原因不是玩家不够聪明，是**这场梦本来就要醒了**：

1. 阿尔弗雷德死了，遗愿压在赫尔曼身上二十年
2. 希尔德加德的改良仪式让血脉断了——**没有下一个画师了**
3. 赫尔曼决定执行遗愿：终结痛苦 = 让梦醒
4. 梦醒的方式是火。火是"擦除"，不是"烧毁"

所以一周目只有两种收场：

| 类别 | 结局 | 触发 |
| --- | --- | --- |
| **意外死** | 若干种 | 选错选项、被道具杀死、梦游踩空、在石门前应答、触摸不当之物…… |
| **业火** | 主结局 | 无论怎么挣扎，赫尔曼都会焚毁古堡 |

### 6.1 业火结局的固定画面

【改】火的中央，赫尔曼的无脸低垂。所有人都没能出去。

**只有弗里德里希侥幸离开。**

他在后花园的碎石路上回头，看见的是：

> **业火中，艾玛平静圣洁的脸。**

不是痛苦，不是求救，不是怨恨。她站在烧塌的门厅里，穿着那身深灰色的女仆装，头发一丝不乱，双手交叠在腹前。她看着他。她的嘴角，是那半个上扬。

**这是全篇最后一次出现那半个上扬。**

（原作写过这个表情三次：L135"像是在笑，又像是在哭"、L241"像在笑。又像是在等待"、L7320"她在火焰中微笑着"。本作把第三次留给艾玛的脸。）

### 6.2 后日谈：悬案

【改】业火结局之后，游戏不结束。进入一段约 8 分钟的后日谈，**视角完全切换**。

#### 后日谈的规格

| 项 | 内容 |
| --- | --- |
| 时间 | 业火之后第十天 |
| 地点 | 勃兰登堡，一间出租公寓所在的街 |
| 视角 | **路人**（不显示主角，主角从不出现） |
| 玩法 | 玩家操控一个无名路人：邮差、女房东、送煤工、巡逻警员。**四个小段，每段换一个人** |
| 核心 | 玩家从路人的对话里，**一点一点拼出"这间公寓里死过人，而且死法说不出口"** |

#### 路人会说什么（示例台词，写作时按 §8 纪律）

- 女房东：「三楼那位先生？……上周的事啦。房租我还留着呢，没人来收。」
- 邮差：「信退回来了。收件人不在——不是搬走那种不在。」
- 送煤工：「我上去过一次。那股味道……不是烂的味道。是……甜的。」
- 警员：「卷宗封了。你不要问我为什么封，我也不知道为什么封。」
- 邻居老太太：「我看见他最后一面，是在楼梯口。他在数台阶。一级，一级，一级。数到第七级，他说——'不对，昨天是六级。'」

#### 房间里有什么（玩家可以走进去）

- 书桌上摊着一本手抄本，抄到一半
- 衣柜里每件外套的内衬都缝着一个小口袋，全部空着（**月兽骨骼不见了**）
- 墙上钉着一张纸：一张画了一半的图纸，缺一角
- 地板上有一个人形的凹陷——**不是尸体的凹陷，是"有人站在这里站了很久"的那种凹陷**
- 窗台上有一小块乳白色的、像玉石一样的碎屑

#### 死亡方式（只在最后一帧给）

玩家走进卧室。镜头停在地板上。

**没有任何血。没有尸体。没有任何东西。**

只有：
- 地板上一个人形的**灰白色的轮廓**，边缘是甜的
- 轮廓的头部位置，压着一张纸——是那张图纸，缺的那一角被补上了
- 补上的那条线，画的是**门厅的拱肋**

然后黑屏。

字幕：

> 卷宗编号 XX92-0419。悬案。
> 死因：不适用。
> 备注：死者生前系勃兰登堡皇家学院预备教员，无亲属，无遗嘱。
> 遗物清单：一本未抄完的手抄本，一支铅笔，一枚银质胸针。
> **胸针上的纹章，档案员不认识。**

最后一行（只有二周目才会亮起）：

> （档案员后来调走了。他说他每次翻到这一页，都会听见有人在数数。）

## 7. 二周目能改变什么

【改】一周目的失败不是惩罚，是**信息**。二周目玩家带着"我知道这个梦会醒"的记忆重来。

### 7.1 里线解锁的东西

| 解锁 | 作用 |
| --- | --- |
| 图纸**底稿层**（Underlay） | 看见箱庭"原本"的结构——它比现在小得多 |
| 童话**空白页** | 一周目洗掉的字，二周目有淡淡的内容 |
| **观察者** | 走廊里一个只在图纸模式下可见的长身人影。它不是活物，是**结构的一部分** |
| 艾玛的台词变化 | 「您回来了，少爷。」 |
| 赫尔曼的台词变化 | 「您上次问了同样的问题。」 |
| 银怀表可读 | 读出"上一次"的时间 |

### 7.2 二周目的目标

二周目不是"打赢"。二周目是**能不能带走一个人**。

| 结局 | 类型 | 条件 | 收场 |
| --- | --- | --- | --- |
| **业火**（重演） | 默认 | 什么都没改变 | 同一场火，同一张脸，同一份悬案 |
| **宝石** | **TRUE** | 三宝石线索齐 + 改良仪式 + 服药 + 问出「你想让我做什么？」 | **原作结局**：他带出了她。三年后成为教授，在废墟遇见维内塔 |
| **不要醒来** | 黑暗 | 终章选择「接手」 | 他成为下一代边框。梦永不终结。所有人都在，但他不再是弗里德里希 |
| **第四颗宝石** | 隐藏 | 连出"艾玛那条线" + 终章选择「不签」 | 所有人都不存在了。只有一个人记得他们 |

**「第四颗宝石」**：三颗宝石是三道门，第四颗是**人**。原作里从来没有第四颗宝石——因为人是最后一颗，而它还没有被磨出来。

**「宝石」为什么是 TRUE**：因为它不是"解决了问题"，而是"做出了唯一正确的那个小动作"。这个家族几百年的病，根子上只有一件事：**没有人给被造物一个姓氏**。

### 7.3 真结局的收束 · 「宝石」

> **硬约束**：真结局必须以原作第 21 章收尾，因为第二部从这里开始。本作**不得**改变这一段的任何事实。

1. 主角在火中问出「你想让我做什么？」
2. 赫尔曼侧过那张无五官的脸，很久，只说：「……您早就知道了。」
3. 燃烧的桁架砸下，维多利亚的画像在火里微笑，赫尔曼的身影消失在火与碎片之后（原作 L7318–L7322）
4. 主角转身走向艾玛。**他没有说"跟我走"。他叫了她的名字，连同那个姓氏**：
   > **「艾玛·冯·祖克霍夫。」**
5. 她答：「……好的，少爷。」——她全篇唯一一句被允许的话
6. 他们走出火场。这次回头，火里没有人
7. **切到三年后**：第一堂课、学院门口的车票、慢车上的抄本、糖堡废墟的无字碑、碎石路上的维内塔
8. 「一起。」（L7833）
9. 全书完。第二部从这句话之后开始

**代价**：他只够救一个人。城堡没了，赫尔曼没了，玛尔塔没了，维多利亚没了，所有的书与手稿都成了灰。他带出来的只有一块月兽骨骼，和一个人。

**为什么这样才对**：

- 这个家族的病，根子上只有一件事：**没有人给被造物一个姓氏**。
- 原作 L21 的叙述者写过"她是艾玛·冯·祖克霍夫"，随即自我更正为"不，她没有姓氏"。全篇唯一一次把那个姓氏真正给她，是在这里。
- 所以"继承"的真正含义不是拿到产业，是**把名字给出去**。

## 8. 表世界不可泄露的清单

以下内容**一周目绝对不能出现**（连暗示都要小心）：

| 禁止出现 | 替代写法 |
| --- | --- |
| 莎布·尼古拉斯 / 奈亚拉托提普 / 犹格·索托斯 / 阿撒托斯的名字 | 只用「原始月亮」「千面之月」「门之钥」「祂」「【】」 |
| "箱庭"这个词 | 只在《黑格林童话》的篇名里出现（原作即如此） |
| "梦会醒"这个说法 | 用「痛苦会累积」「终结」这类词绕开 |
| "你是被画出来的" | 用「您没有碎片，您是一个人」反向表述 |
| "这个家族是边框" | 用「管家、会计、采购员、园丁、维修工」这类职务清单暗示 |

**允许的暗示上限**（一周目最多用到这一层）：

1. 地理是错的——东弗里斯兰的群山挨着黑森林，多特蒙德在它们边缘（真实德国地理不成立）
2. 图纸上的建筑会变
3. 所有人都在解释同一件事，但没有人解释得一样
4. 火会变成形状
5. 死掉的人"没有被找到"
6. 有人说过"所有的角色都死了"

## 10. 写作纪律

1. **表世界要好看。** 一周目是一座哥特古堡冒险故事，有糖、有礼仪、有齿轮、有火。它自己就成立。玩家不需要神秘学知识也能享受。
2. **里线要经得起回看。** 二周目的每一句"原来如此"，都必须能在一周目里找到那句原话。
3. **不做信息倾倒。** 里线的真相通过"重读"给出，不通过"解释"给出。
4. **名字只在二周目出现，且只出现一次。** 三柱神的名字各出现一次，阿撒托斯永远不出现。
5. **恐怖要克制。** 一周目的死法是"意外"；后日谈的死亡是"说不出口"。这两者的差别就是本作的恐怖来源。
6. **不要给玩家希望，除非你已经准备好收回它。** 一周目的艾玛没有救，二周目的艾玛也不是靠"攻略"留下来的——她是靠主角**接手**留下来的。
