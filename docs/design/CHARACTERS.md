> 本文是**唯一权威**的人物关系表。凡出现「维多利亚」「罗泽莉亚」「希尔德加德」「维内塔」的地方，以本文为准。

## 1. 祖克霍夫家的血脉

```
维多利亚·斯图亚特（卡美洛苏格兰王室公主）
   │  娘家姓斯图亚特；曾祖母
   │  红发、深蓝眼、苍白、黑长裙、铁十字黑秃鹫银胸针
   │  丈夫 = 威廉·冯·祖克霍夫（与主角同名，曾祖父）
   │
   ├─ 后代（中间代，小说未详述）
   │     │
   │     ├─ 阿尔弗雷德·冯·祖克霍夫（外祖父，上一代家主）
   │     │     墓碑刻「糖庄的守护者」，XX38–XX95
   │     │
   │     └─ 希尔德加德·冯·祖克霍夫（母亲）
   │           XX64–XX92，二十八岁去世，陵园有铜牌
   │           赫尔曼对她有特殊感情（「唯一一个让赫尔曼笑过的人」）
   │
   └─ 弗里德里希·威廉·冯·祖克霍夫（主角）
         红发、深蓝眼——与维多利亚画像一模一样
```

**写作纪律**：
- 维多利亚永远是**曾祖母**，不是母亲、不是祖母
- 希尔德里希——错，是**希尔德加德**——永远是**母亲**，且**不出场**（只有铭牌与转述）
- 主角与**曾祖父同名**（威廉·冯·祖克霍夫），这是小说里的一个刻意的重复，不要"修正"

## 2. 罗泽莉亚 = 维多利亚的另一个名字

**作者确认（本次）**：罗泽莉亚是**维多利亚成为吸血鬼之后的化名**。

原作番外的原文并置（L7880 一带）：
> 维多利亚·斯图亚特。卡美洛联合王国苏格兰王室的公主。维多利亚·冯·祖克霍夫。弗里德里希·威廉·冯·祖克霍夫的妻子。聚斯霍芬堡曾经的女主人。铁红洋馆的主人。罗泽莉亚。蔷薇。

她自己说的话（L7952）：
> 「罗泽莉亚。不是维多利亚。罗泽莉亚。Rozelia，蔷薇。」

**这意味着**：
- 番外里那位「公主装、银白发」的罗泽莉亚，与门厅画像上的红发女人是**同一个人**——只是过了很久，红发褪成了银白
- 她是**不吸人血的吸血鬼**（L8086），这一点是她这个角色最核心的矛盾
- 在游戏里的用法：
  - 一周目：只有**维多利亚**这个身份出现（画像、族谱、童话名录里的同名）
  - 二周目 / 番外：**罗泽莉亚**这个名字才登场
  - **里线的命名揭露**：当玩家发现"维多利亚 = 罗泽莉亚"时，童话名录里那个"维多利亚"就不再是巧合

## 5. 三层命名的一致性检查

同一件东西在不同层要有不同的叫法——写目录时对一下：

| 层 | 维多利亚 | 艾玛 | 弗里德里希 |
| --- | --- | --- | --- |
| 一周目（表层） | 「曾祖母」「画像上的女人」 | 「女仆」「艾玛」 | 「少爷」「弗里德里希」 |
| 二周目（里线） | 「罗泽莉亚」「她」 | 「第三个」「那个不是人的」 | 「第四个」 |
| 真结局（第 21 章） | 不再出现 | 「艾玛」——他终于叫出「艾玛·冯·祖克霍夫」 | 「教授」 |

**禁止**：在一周目让任何人说出「罗泽莉亚」三个字。这个名字是二周目的钥匙。
