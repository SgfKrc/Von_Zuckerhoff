## 二、三个缺口的详细设计

### 缺口一：场景 4 · 法兰克福插叙（L250–332）

**为什么必须补**：这不是"补充材料"，是整部作品的**阶级底色**。没有这一段，玩家不会明白"红毛怪""糖贩子"这些辱骂为什么重要，也不会明白他为什么对"有姓氏"这件事那么敏感。

**原作内容**（七段）：
1. 二十一岁才第一次看见大海之前，他活在法兰克福的煤灰与硫磺味里
2. 十二岁进冶金工厂：木底鞋、帆布手套、搬纱锭（一天两百趟、一月六千趟）
3. 夜校老师告诉他皇家学院的存在（全帝国每年招六十人，学费全免）
4. 抄书：抄《算术原理》、半本《解析几何》、三分之一《自然哲学的数学原理》——**后来才知道原书是拉丁文，他抄的是译本，很多地方翻错了**
5. 考试：穿蓝工装站在天鹅群里，教授摘下眼镜又戴上说"那你应该考不上"——**他考上了，第五十九名，倒数第二**
6. 学院三年：第一年追赶、第二年持平、第三年领先；数学第一、物理第二、总成绩第五
7. 船厂五年：月薪一百二十马克，实际工作是端茶倒水

**建议形式**：**木刻蒙太奇**

原作在 L499 提到"画面切换为木刻风插画"——就用这个形式。做成一段不可操作的过场（像开场分镜那样），**7 个静态画面 + 旁白**，每个画面 1–2 句，总长约 40 秒。

- 画面用**程序化木刻风格**（黑白、粗刻线、留白大）
- 旁白用现成的打字机（28 cps）
- 位置：第一夜**睡着之后**触发（进卧室 → 睡下 → 闪回 → 醒来）
- 关键：第 4 段的"抄错译本"和第 5 段的"倒数第二也是考上了"必须保留，这是他人设的骨头

**工作量**：中。7 张程序化木刻图 + 一段过场播放器（可以复用开场分镜的骨架）。

### 缺口二：场景 11 · 礼仪课（L787–891）

**为什么必须补**：这是全章**信息密度最高**、也是**艾玛性格最立体**的一场。她在这里第一次露出"不是人"的痕迹（年龄、那句"这是玩笑"）。

**原作内容**（五段）：
1. 餐桌礼仪：主人坐长桌中央背对壁炉、女主人正对面、教士优先于世俗贵族
2. **三重追问与三次裁定**（最精彩）：
   - 两位公爵？→ 按封地年限，更古老的优先
   - 年限一样？→ 按与皇室的血缘亲疏
   - 亲疏一样？→ "通常意味着有人在挑衅。届时您需要做的不是排座位，而是请他们去庭院里用剑解决问题。" → "这是玩笑，少爷。" → 他找不到说笑的痕迹
3. 皇帝全称（那段又长又荒谬的念白）+ "为了让您知道省略版省略了什么"
4. 艾玛的脸很近：银色卷发的光泽、呼吸的温度、"像一把没出鞘的刀抵在喉咙上"
5. 艾玛的年龄：她说"很久""足够久"，可脸看起来最多二十五岁——"被时间遗忘的、被颜料凝固的"

**建议形式**：**问答小游戏**

艾玛提问，玩家从 3 个选项里选：
- 答对 → 她的反应是"记录"（冷淡的肯定）
- 答错 → 她纠正，然后**重复一次正确的**（像录入）
- 三次追问那题做成**连环问答**（连续 3 个问题，最后一个选项里藏"用剑解决问题"）

答题产物：`etiquetteScore`（礼仪分），影响后面章节的社交场合（第六章千面之月的宴会）。

**工作量**：中。一个问答 UI + 约 25 句台词。

### 缺口三：场景 12 · 深夜书房《黑格林童话》（L893–1041）

**为什么必须补**：这是**全篇的里线钥匙**。没有它，后面十二章的外神体系没有根。

**原作内容**（九段，几乎需全文保留）：
1. 献词（写给"格林"）
2. 世界设定（被浓雾笼罩的国度、没有名字的不死人）
3. **创世说**：「这个世界是【】创造的。【】在梦里梦见了一位艺术家…」（【】是全篇最重要的符号）
4. 角色名录（小红帽、灰姑娘、……**维多利亚**……）
5. **命中注定的名字**：读到"维多利亚"时他停住——"这是巧合吗？"
6. 影子们的愿望（"假的也没关系。只要还有人记得，假的也可以是真的"）
7. 写作伦理（"写故事的人要对故事里的人负责"）
8. 主线摘要（格林、爱丽丝、四大魔姬）
9. 师徒设定（多萝西）

+ 最后一页的**木刻插图**（站在荒原上的年轻人、燃烧的城堡、满地白骨）+ 图下小字「这就是我。这就是我做的。这就是我必须做的。」

**建议形式**：**分页阅读界面**

- 一本可翻页的书（左右箭头翻页，共 9–10 页）
- 每页一屏文字（打字机效果）
- 「【】」在两处出现时**高亮**（这是玩家第一次看到这个符号）
- 读到"维多利亚"那一页时，**画面轻微震动 + 一声低音**（他停住了）
- 最后一页是木刻插图（程序化绘制）
- 读完后触发三个自问（【】是什么 / 威廉是谁 / 塔里有什么），并解锁成就「黑格林童话」

**工作量**：中偏大。阅读 UI + 10 页文本 + 一张木刻插图。

## 三、两个小补丁

### 补丁 A：场景 8 的"房间索引"
原作那段 18 个房间的巡游清单（客厅、起居室、图书室、音乐室、台球室、会客室、吸烟室、宴会厅、小餐厅、厨房、储藏室、食品库、酒窖、洗衣房、缝纫室、熨烫室、陶瓷室、银器室），以及艾玛"只有索引，没有正文"的引导方式。

**补法**：在 `arriveCorridorMain` 或 `arriveGarden` 里加 3–5 句，让艾玛念一部分房间名，主角数着数着数不清。不需要做 18 个房间。

### 补丁 B：场景 10 的"母亲"
艾玛那句「您母亲，她是这座古堡里唯一一个让赫尔曼大人笑过的人。」

**补法**：在 `lookVictoria` 之后加一段（`talkEmmaMother`），或者并进 `talkEmmaDining`。

## 四、工作量排序（建议的补齐顺序）

| 顺序 | 缺口 | 理由 |
| --- | --- | --- |
| 1 | 补丁 A + B（房间索引、母亲） | 成本极低，立刻让第一章"厚"起来 |
| 2 | 场景 11 礼仪课 | 信息密度最高，且是艾玛性格的立点 |
| 3 | 场景 12 黑格林童话 | 里线钥匙，但需要阅读 UI |
| 4 | 场景 4 法兰克福插叙 | 需要 7 张木刻图，成本最高，但阶级底色不能少 |

**顺序 2 和 3 可以互换**——如果优先"章末悬念强"，就先做 12；如果优先"角色立住"，就先做 11。
