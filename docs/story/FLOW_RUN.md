## 二、三个 P0（已修）

### P0-1 · 第一夜睡下之后链条断掉（**自己改出来的死锁**）

`beginExplore()` 是 `montagePending` 的唯一消费者，而 `beginExplore()` 只在**章节卡按键**时调用——但章节卡又在**蒙太奇之后**。绕成环：

```
endPrologue（没 chapter）→ 无章节卡 → 无 beginExplore
→ montagePending 没人消费 → 蒙太奇不播
→ 无 wakeAfterMontage → 无 chapter → 永远卡住
```

实测状态：`{mode:"explore", card:false, montage:null, pending:true, saw:false}`

**修法**：`endPrologue` 末尾直接加 `{ montage: 'frankfurt' }`（`applyEffects` 已支持 `e.montage`）。跳过章节卡这一环，环就断了。

**教训**：把一个 effect 从 A 挪到 B 时，要顺着"谁触发谁"走一遍闭环。我上一轮把 `chapter` 从 `endPrologue` 挪到 `wakeAfterMontage`，只看了"时间线更顺"，没看"触发链会不会断"。

### P0-2 · 落点即出口（5 处，不是 2 处）

| 传送 | 落点 | 冲突的回程门 |
| --- | --- | --- |
| gate → hall | (12,14) | hall 的 (12,14)→gate |
| bedroom1 → corridorE | (26,6) | corridorE 的 (26,6)→bedroom1 |
| dining → corridorMain | (20,8) | corridorMain 的 (20,8)→dining |
| corridorMain → dining | (1,12) | dining 的 (1,12)→corridorMain |
| parlor → library | (28,12) | library 的 (28,12)→parlor |

`portalCooldown` 只有 16 帧（0.27 秒），而入场白有 7 秒——冷却早耗光，玩家一落地就被弹。

**修法**：5 处落点各错开一格。

**`check-map` 为什么没抓到**：那行写的是
```js
const clash = targetPortals.find(q => q.x === +tx && q.y === +ty && q.to !== from)
```
`q.to !== from` 本意是"排除落在同源门上"，但**回程门恰恰就是通往来源地图的**——排除条件把唯一有害的情况放过了。已去掉。

> **校验脚本的"排除条件"往往就是 bug 的藏身处。**

### P0-3 · 第一章 6 张图与序章完全不连通

跨图 BFS 结果：
- 可达：`train → station → road → gate → hall → cellar / bedroom1 / corridorE`
- **不可达**：`dining / library / corridorMain / bridge / garden / parlor`

门厅只有 3 道门（gate / cellar / bedroom1）。「大厅不能直通走廊」是序章的硬约束，但**没给第一章留入口**——第一章开始时玩家在卧室，出卧室只能到门厅，然后没路了。

**修法**：`hall` 东侧加一道 `→ corridorMain` 的门，`lockFlag: 'chapter1'`。序章锁着，第一章开放。

### 3.1 过场不能中途跳

`跳过` 永远只落在该段的**最后一帧**。玩家想快点看中段内容，只能等满。

| 段 | 时长 |
| --- | --- |
| 开场分镜 | 31.7s |
| 到站演出 | 11.1s |
| 木刻蒙太奇 | 31.1s |
| **三段合计** | **≈74s，且集中在开局 65 秒内连吃两段** |

**建议**：跳过改成"快进 2×"，而不是"跳到结尾"。或者按段落跳（每按一次跳一段）。
