## 四、已知缺陷

### P0 · 影响可玩

_（无）_

### P1 · 影响体验

1. **梦游机制未实装**（SYSTEM_DESIGN §6.5）。它是「踩空」结局的唯一入口；切片未做，所以目前只有「弃婴」一种死亡。
2. **甜醉只有视觉**，没有"坐标提示错误 / 图纸噪点"的功能惩罚。
3. **对话没有打字机效果**，长台词一次性刷出。
4. **石桥的峡谷感仍不足**：悬崖瓦片（`h`）是"崖顶草缘 + 堆叠岩块"的画法，俯视密排后仍偏像石壁。更好的做法是深色虚空 + 崖缘高光。

### P2 · 打磨

5. 序章列车地图偏空（只有 2 个座位实体 + 3 个调查点）。
6. 走廊画像间距不均（手工摆位，未按节奏排）。
7. 部分地图的房间形状过于方正，缺少"古堡"的不规则感。
8. 成就「不对劲」需要三处异常，但没有"保底"提示，玩家可能带着两处就进第一章。

## 六、工程教训（避免重复踩）

1. **不要用 `(?s)` 正则整块替换 `maps.ts` 里的 `const xxx: GameMap = {...}`**。非贪婪的 `.*?\n\}\n\n` 在文件末尾的定义上会一路吃到下一个定义，把后面的地图一起删掉。本轮因此两次丢失了 `parlor`（接待厅），且 `check-map` 只会报"传送门目标不存在"，不会告诉你"定义没了"。
   - 正确做法：按 `IndexOf("export const START_MAP")` 之类的锚点做**子串插入**，或者人工编辑。
2. **同一块瓦片密排会变成另一种东西**。石地密排成墙、桌子密排成文件柜、悬崖密排成砖墙。判断方法：把画面给没看过设计的人看，问"这是哪里"。
3. **Vite 的 fs watcher 会被 headless 浏览器的缓存目录撞崩**（`EBUSY`）。截图时 `--user-data-dir` 必须指向项目外，且 `vite.config.ts` 的 `watch.ignored` 要覆盖 `.preview/**` 这类目录。
4. **并行 agent 会撞坐标**。开场 agent 与列车 agent 同时改，前者把玩家送到 `train (3,7)`，而后者刚把地图改成一墙一格，`(3,7)` 变成了内饰板。集成时必须逐条核对跨文件的坐标与 key。
5. **`=` 字符已被车厢壁占用**，原墓碑瓦片让位（`drawGrave` 保留但未注册）。第三章陵园开工前必须先给墓碑分配新字符。
