### 1.2 地图三层数据

```ts
interface GameMap {
  id: MapId
  name: string
  ambient: 'indoor' | 'fog' | 'alley' | 'night' | 'fire' | 'dream'
  dark: number            // 0~1 基础黑暗度
  tiles: string[]         // 现实层：美术瓦片字符
  struct: string[]        // 结构层：图纸层字符（尺寸必须与 tiles 完全一致）
  entities: EntityDef[]
  portals: Portal[]
  revisions?: Revision[]  // 章节推进时对 struct 的改写
}
```

**结构层字符表**（图纸层渲染唯一依据）：

| 字符 | StructKind | 视觉 |

| `V` | void | 空 |
| `F` | floor | 可走 |
| `S` | stone | 承重石墙（剖面线） |
| `B` | brick | 非承重砖墙（可拆） |
| `K` | fake | 假墙（剖面线 + 红叉） |
| `M` | beam | 木梁 |
| `A` | arch | 拱肋（承重点） |
| `P` | pipe | 管道 |
| `R` | rail | 滑轨 |
| `G` | gear | 齿轮 |
| `W` | weight | 配重 |
| `H` | shaft | 竖井 |
| `T` | stair | 楼梯 |

### 1.4 传送与锁

- 传送点坐标必须是**目标地图的可走格**，且**两端都不在实体上**
- 锁用 `lockFlag`：flag 未满足时弹回并给 `lockMsg`
- `lockFlag: 'neverOpen'` 永久不可通过（用于"看得见但过不去"的门）
- 单向门：目标地图的返回 `Portal` 设 `lockFlag: 'chapterN'`，章节推进才开

### 1.5 调查点密度

| 地图类型 | 调查点/千格 | 说明 |
| --- | --- | --- |
| 教学图 | 6–8 | 序章，宁多勿少 |
| 主叙事图 | 3–5 | 卧室、门厅、教室 |
| 走廊/连接图 | 1–2 | 不堆文本 |
| 谜题图 | 2–3 | 密度让位给机关 |
| 对峙图 | 0–1 | 打断注意力是错的 |

**单条风味文本上限 40 字。** 超过就拆成两条，或者做成"再按一次 E 往下读"。

### 1.6 每章节奏模板（40–90 分钟）

| 段落 | 占比 | 内容 | 情绪 |
| --- | --- | --- | --- |
| A 开场 | 10% | 章节卡 + 童话一则 + 一张图 | 静 |
| B 探索 | 25% | 2–4 张地图，建立本章空间 | 松 |
| C 发现 | 15% | 一处图纸异常 → 一个目标 | 紧 |
| D 解法 | 25% | 补图/对峙/社交，主谜题 | 最紧 |
| E 揭示 | 15% | 信息高潮，玩家"懂了" | 释放 |
| F 收束 | 10% | 图纸更新 + 章末悬念 | 空 |

### 1.7 谜题配置原则

- 每章 **3–6 个补图点**（含可选）
- 每章 **1–2 个非补图谜题**（排序、社交、纸面、时间）
- 每章至少 **1 个可选谜题**（给了奖励，不做不影响主线）
- 谜题必须挂在 `GAMEPLAY_MATERIALS.md §2` 的 P 编号上；新建谜题要补进那张表

### 1.8 校验清单（每次改地图/剧本后必跑）

```
□ tiles 每行等宽且行数一致
□ struct 与 tiles 尺寸完全一致
□ 所有 Portal 目标地图存在、坐标可走
□ 所有 Portal 的 lockFlag 有对应的解锁 flag
□ 所有 Entity.interact 在 events 里存在
□ 所有调查点至少 1 条文本，且有 flag 变化的分支
□ 每章的 revision 目标格存在
□ 从章节起点 BFS 可达所有必需交互点
□ 每个对峙的 beats 与 weaknesses 完整
□ 存档/读档后 revision 已应用状态正确
```

### 必修补图

**BP-1-1 时计塔立面测量**（本章标志性谜题）
- 玩家在石桥上进入图纸模式，塔的立面在图纸上展开
- 用标尺量：塔壁 3 格，凹槽深 9 格
- 玩家需要把测量线**拖进凹槽**并标记 → 出现"凹槽穿透塔壁"的判定
- 成功后：远景上塔身的四个凹槽同时亮一下就灭（视觉奖励）
- `conviction +8`

**BP-1-2 地窖配重门**（可选）
- 三根梁跨度 3:2:1，玩家要在配重槽里补一块对应重量的石头
- 成功 → 门开一条缝，里面传来"数数"的声音

### 验收标准

1. 玩家在本章结束时能画出古堡一层的简图（认知地图成立）
2. 时计塔谜题必须让玩家**主动测量**，不能给提示箭头
3. 家族史"甜→苦"的节奏必须让玩家在读第 4 页时停下来
4. 地窖的"数数"声可听到，但不解释

4. 孤儿院梦必须暖色，且没有目标

### 巨齿轮：三层叠图（本作旗舰谜题）

**原文依据**：L4149–L4151（没有啮合、没有传动轴、没有皮带链条连杆）；L4503（「它只是没有连接您看得见的东西」）。

谜题要求玩家画**三层图**，每层解决一个问题：

| 层 | 图纸模式下按 | 显示什么 | 玩家由此得到的结论 |
| --- | --- | --- | --- |
| ① 可见传动层 | `1` | 只有现实中的齿轮与轴 | 空的——没有输入，也没有输出 |
| ② 结构层 | `2` | 承重、腔体、地面材质 | 齿轮底部与地面**一体成型**，量不到接缝 |
| ③ 不可见传动层 | `3` | 塔身凹槽、墙上小齿轮、管道声源、月光流向 | 一条**穿墙的力线**，从塔顶凹槽穿到齿轮轴心 |

- 第 ③ 层是**条件解锁**：必须先完成第一章的"凹槽比塔壁深"测量，并听过本章的管道声音，`3` 才会出现。没做过就只能停留在第②层，并得到一句提示："您还没量够。"
- 解锁后图纸上出现 **11 格虚线缺口**（从凹槽投影到轴心）
- 补图校验：同轴、连续、不穿 `S`/`A`、齿轮咬合 ratio 一致、两端闭合
- 落笔成功 → 巨齿轮转**一格** → 停下 → 塔里响一声钟（**塔里没有钟**）
- **玩家以为通关，其实只是理解的开始**

**为什么这样改**：单层"补传动链"是普通机械谜题；三层叠图把谜题变成了"**你必须先承认自己看不见某些东西**"。第二层回答"它怎么造的"，第三层回答"它在被谁驱动"——这两问的答案都不在现实里。

### 十二个名字排序规格

- 界面：速写本上一棵空树（12 个节点）
- 12 个名字以"声音"的形式在走廊里出现，玩家记下顺序（可回看笔记）
- 玩家把名字拖进树的节点
- 唯一正确答案：按位阶从低到高（叶子 → 树干）
- 提示只来自童话《十二张脸》的间接暗示
- 排错 → 名字叠加、出现"拼不起来的脸"、可重试（无惩罚，只有视觉）
- 排对 → 名字熄灭，只剩"弗里茨"

### 验收标准

1. 十二个名字必须能靠已有文本推出来，不能靠穷举
2. 巨齿轮"转一格"必须是玩家操作的直接结果

### 对峙 4 · 混沌之形

- 三步：
  1. **按住 `E`**（凝视）。屏幕逐渐扭曲、噪点、反色。按得越久 `conviction` 掉得越快，但"舍弃比例"越高。松手结算。
  2. 屏幕几乎全白时输入"最初的名字"（四选一：弗里茨／弗里德里希／全名／施密特）。正确 = 弗里茨。
  3. 震动 + 白屏 → 疼痛消失。
- 成功：`traces.releasedFaces = true`，`conviction` 上限 +10，图纸上几条 `I` 变回 `F`
- 失败：少一段孤儿院记忆（第二章梦境的一个孩子从梦里消失）

### 八幅画像应答规格

- 8 次选择 × 3 选项
- 累积成"立场"：`stance = { nod: n, silent: n, own: n }`
- 终章判定用：多数 nod → 继承人路线；多数 silent → 旁观者；多数 own → 作者路线
- **不给任何反馈**（不能提示"你的立场是……"）

### 验收标准

1. 钢琴踏板必须让玩家真的踩三次（有音高反馈）
2. 混沌之形的凝视必须有生理不适感（不靠 jump scare）
3. 握把的文本输入框必须让玩家停顿超过 10 秒
4. 阳台的 10 分钟奖励必须有，但不给任何提示

### 无限阶梯规格

- 视觉：纵向滚动，每层平台有窗洞
- 玩家往上走，每 3 层回到相似平台
- 图纸模式：显示台阶高度数值（3.0 → 2.9 → 2.8……）
- 正确解法：**在数值停止递减的那一层调头向下**
- 调头后：阶梯恢复正常，通到塔顶
- 若玩家一直往上：层数计数到 99 后，回到起点（不惩罚，只给一次"你走错了"的环境音）

### 三件事选择规格

- 三张卡片同时浮现，屏幕被三束光分割
- 玩家只能点一张
- 选中后：其余两张**碎裂**（视觉），永久不可再读
- 三张的内容：

| 卡片 | 展开内容（游戏原创，须与番外序列设定一致） |
| --- | --- |
| 1. 千面之月与挪威祖母绿 | 千面之月是恶魔分支的源头，挪威祖母绿是它的"颜色"；月兽是它的碎片；恶魔后嗣是它与吸血鬼分支的交点 |
| 2. 完整骨架 vs 一块碎片 | 埃里希做的是"剥脸仪式"（全数献出），老弗里德里希做的是"转化"（只取一块）——所以一个得到骨架，一个只得到碎片 |
| 3. 齿轮为什么停 | 它不是在计时，是在**计数**：每一代家主签名的次数。签名者终，齿轮停 |

### 验收标准

1. 限时搜索必须让玩家明显感到"我少知道了一件事"
2. 无限阶梯的解法必须是玩家自己"量"出来的
3. 月光时钟是技术标杆，必须跑满 60fps
4. 三件事的选择必须让玩家犹豫超过 30 秒
